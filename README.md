# MyTech сайт — бараагаа өөрөө засах заавар

## ХАМГИЙН ХЯЛБАР АРГА: Google Sheet (нэг удаа тохируулна, дараа нь зөвхөн хүснэгт засна)

### Нэг удаа хийх тохиргоо
1. https://sheets.new нээнэ. **File → Import → Upload** → `products.csv` сонгоно → "Replace spreadsheet" → Import.
2. **File → Share → Publish to web** → "Entire Document" оронд хүснэгтийн хуудсаа (Sheet1) сонгоно, хажуу талд нь **"Comma-separated values (.csv)"** сонгоод **Publish** дарна. Гарч ирсэн линкийг хуулна.
3. `index.html`-ийг нээж (GitHub дээр ✏), `sheetUrl:''` гэсэн мөрийн хоёр хашилтын дунд линкээ буулгаад Commit хийнэ.

### Өдөр тутам
- Хүснэгтэд үнэ, нэр засна.
- **stock** баганад үлдэгдлийн тоог бичнэ (жишээ: `5`).
  - Хоосон = үлдэгдэл тоолохгүй, хэзээд захиалж болно.
  - `0` = "Дууссан", сагсанд нэмэгдэхгүй.
  - `1`–`3` = сайт дээр "⚠ Сүүлийн N ширхэг" гэж улбар шар өнгөөр харагдана.
  - Хэрэглэгч үлдэгдлээс илүү тоо сагсанд хийж чадахгүй. Захиалах үед сайт үлдэгдлийг дахин шалгана.
- Хэрэв нэг барааг үлдэгдэлгүйгээр шууд дуусгах бол **soldout** баганад `TRUE` гэж бичнэ.
- ⚠ Үлдэгдэл автоматаар хасагдахгүй. Захиалга баталгаажсаны дараа та **stock** тоог өөрөө 1-ээр хасна. Сайт дээр ямар ч сервер байхгүй тул энэ хэсгийг гараар хийнэ.
- Шинэ бараа нэмэхдээ шинэ мөр нэмнэ. **type** баганад `pc`, `monitor` эсвэл `package` бичнэ.
- 1-5 минутын дараа сайт өөрөө шинэчлэгдэнэ. GitHub-д юу ч оруулах шаардлагагүй.
- **price** дээр зөвхөн тоо бичнэ (жишээ: 4500000).
- Хүснэгтийг зөвхөн итгэсэн хүндээ Edit эрхтэй хуваалцана.

## Нөөц арга: products.json + admin.html
Сайтад `products.json` бас байгаа. Google Sheet холбогдоогүй эсвэл ачаалахгүй үед сайт үүнийг ашиглана. `admin.html` хуудсаар засаад "products.json татах" → GitHub дээр солиулж оруулна.
Дансны мэдээллийг (банк, IBAN) `products.json` дотроос засна.

## Хүснэгтийн баганууд
type | brand | name | cpu | cooler | board | ram | gpu | storage | price | stock | soldout | note
- `pc`: name=PC-01, cpu, board, ram, gpu, storage, price
- `package`: name, cpu, cooler, board, ram, storage, price, note
- `monitor`: brand, name, note (тайлбар), price
